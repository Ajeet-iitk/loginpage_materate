# MateRate - Login Page

A login screen concept for MateRate, built with plain HTML and CSS.

## What it is

A design exercise: one login screen, taken seriously. Background photography, a logo lockup and a form card, with the state styling handled in CSS.

## Run locally

Open `index.html` in a browser.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The login screen |
| `logo.png`, `logo.jpg` | Brand mark |
| `favicon.ico` | Site icon |
| `*.jpg` | Background photography |
